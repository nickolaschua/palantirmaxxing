# Public

Static files served by Vite and copied into production builds. `population.geojson` is generated by the offline preparation command from verified cached official sources; it is ignored by Git. This document keeps the directory trackable.

The artifact includes all source zones and shared metadata for the map, chart and details. Acquisition, joins, area and density calculations belong in `backend/data_sources/`; no official-source queries occur in the browser. Add other public assets here only when they need stable URLs.
