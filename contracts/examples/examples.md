# Examples

`pec-result.json` is the complete `pec-result/1` output generated from [the supplied example episode](../../data/scenarios/pec-example.json) and [synthetic population fixture](../../tests/fixtures/pec-population.json). It illustrates all result totals, event/zone breakdowns, coverage and calculation metadata; event 2 includes optional time.

Regenerate with the README PEC command, changing `--output` to `contracts/examples/pec-result.json`. Runtime outputs normally belong in `data/results/`. Contracts are documented in [PEC formats](../pec.md), including an invalid-input example and nullable partial-coverage fields.
